2. The buttons

Emoji, name, a short description, and the address (for a page on asl.cool, just the part after asl.cool/, like fingerspelling/; for another site, the whole address starting with https://).

You always see every button after typing your own password. Under each button, tick 🔑 the passwords that should open it, and tick a teacher link to put it on that link.

Passwords (for classes, teachers or anyone)

Make a password for anyone: a class, a class period, another teacher, a family. Whoever types it on asl.cool sees only the buttons you tick for that password (the 🔑 ticks under each button). Each must be different, and different from your own password. Remove a password and it stops working right away. You type your own password in the same box to see everything.

Teacher Links

Each link has a random code nobody can guess, and shows only the buttons you tick for it. Remove a link and it stops working right away. The names are only for you; teachers never see them.

3. New password (optional)

Leave both empty to keep the current password.
