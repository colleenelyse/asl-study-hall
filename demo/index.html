Try these in about 5 minutes

  1. Give points from the Teacher dashboard. Tap two or three students, then +5 Tickets: this is how students are rewarded for signing in class. They see it the next time they open the app. Open the dashboard →
  2. Host a class game. 1 vs. The Mob is picked for you: tap Open the lobby, then Start the game. The sample class joins and answers on the projector screen, just like a real class. Tower Climb and Race Day play with the class too. Open Host a game →
  3. See what the class finds hard. Vocab stats shows which signs each class gets right and wrong; the seating chart and group maker use the same classes. Vocab stats → Seating chart → Group maker →
  4. Study as a student. Practice the Unit 2 signs with real ASL videos, then see how practice adds up to a test score on the Summative Stacker. Start studying → Summative Stacker →
  5. Play. Try a solo story game, then the 3D signing hand and the webcam reader. Games → Fingerspelling & Numbers →

Good to know: the camera games (fingerspelling and numbers to the webcam) work best in Chrome. The sample classes are made up; no real student names or data are in this demo.
